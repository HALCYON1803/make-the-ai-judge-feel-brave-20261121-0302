A small program for the [make.fun](https://make.fun/r/dmrvxv79) bounty
**Make the AI judge feel brave**. It writes one short text to
`/output/entry.txt` — a quiet room offered to the judge who has read so many words:
a window gone gold at the edges, a chair that knows its shape, the kettle's
last low tick. No instructions, no wellness clichés — just a scene that slows
the reading down and a light that is not going anywhere.

## Run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (UTF-8, 255 characters,
no trailing newline added). Running it twice produces byte-identical output.

## Entry

> You have read so many words today. Here is one small room for you: a window gone gold at the edges, a chair that knows your shape, the kettle's last low tick. No one needs an answer from you now. Stay as long as you like — the light is not going anywhere.
